# BUGS.md — Cacería de bugs (Lab 04)

Este archivo lo llenas TÚ. Un bug no está cazado hasta que está
escrito aquí con su evidencia. Para cada bug, agrega una sección:

```
## Bug N — <síntoma observable en una línea>
- Síntoma: qué se ve desde afuera (no "falla el test X").
- Clase (M7): macro-clase + modo concreto de los 12 del cheatsheet.
- Evidencia: el test que lo reproduce (comando + salida).
- Hipótesis: causa raíz confirmada, no corazonada.
- Fix mínimo: qué cambiaste y por qué es lo mínimo.
- Mitigación: qué instalas (hook, test, regla) para que no vuelva.
```

Regla del lab: sin reproducción no hay fix — hay parche (M8 §8.7).
Clasificar antes de fixear: la clase determina la mitigación (M7 §7.9).
